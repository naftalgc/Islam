تطبيق محطة نفطال – نسخة PWA

محتويات المشروع:
- index.html: التطبيق الأصلي مع تهيئة التثبيت.
- manifest.webmanifest: تعريف التطبيق وأيقونته.
- service-worker.js: تخزين ملفات التطبيق للعمل دون إنترنت بعد أول زيارة.
- icons/: أيقونات التطبيق.

النشر عبر GitHub Pages:
1) أنشئ مستودعاً جديداً (Repository) في GitHub.
2) ارفع كل محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP فقط.
3) من Settings > Pages اختر Deploy from a branch.
4) اختر الفرع main والمجلد /(root)، ثم Save.
5) افتح رابط GitHub Pages على هاتف Android باستخدام Chrome.
6) من قائمة Chrome اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".

ملاحظات:
- يلزم HTTPS لتثبيت PWA؛ GitHub Pages يوفر HTTPS.
- بعد أول فتح ناجح، تُخزّن ملفات الواجهة الأساسية لتعمل دون إنترنت.
- البيانات المدخلة محفوظة محلياً في المتصفح نفسه (LocalStorage)، وليست مزامنة سحابية.
- لا تحذف بيانات المتصفح قبل تصدير/نسخ بياناتك احتياطياً.
- الخطوط الخارجية قد تحتاج إنترنت أول مرة، لكن وظائف التطبيق الأساسية لا تعتمد عليها.
